# 과제 채점 도우미 · 사용설명서

학생이 낸 과제를 AI가 채점 기준대로 채점·피드백하고, "과목별 세부능력 및 특기사항(세특)" 초안까지
만들어 주는 도구입니다. 문제은행 기반 적응형 문제풀이, 평가계획 자동 분해, 학습 분석도 함께 담았습니다.

- **접속 주소**: https://cat-webapp.vercel.app
- **권장 환경**: 최신 크롬 · 엣지 · 사파리

> 이 문서는 사용자(관리자·교사·학생)를 위한 안내서입니다. 설치·자체 배포 방법은 [README.md](../README.md)를 참고하세요.

## 시작하기

### 접속과 로그인

모든 사용자는 위 주소로 접속해 **이메일과 비밀번호**로 로그인합니다.

- **학생**은 로그인 화면의 "회원가입"에서 스스로 가입합니다.
- **교사·관리자** 계정은 스스로 가입할 수 없고, 관리자가 발급해 준 이메일·임시 비밀번호로 로그인합니다.
- 로그인하면 역할에 맞는 화면(교사 대시보드 / 학생 대시보드 / 관리자 페이지)이 자동으로 열립니다.

> 💡 **팁** — 처음 받은 임시 비밀번호를 쓰고 있다면, 로그인 후 곧바로 본인만 아는 비밀번호로 바꿔 주세요.

### 역할 이해

세 가지 역할이 있고, 할 수 있는 일이 서로 다릅니다.

| 역할 | 할 수 있는 일 |
|---|---|
| **관리자** | 교사 계정을 발급합니다. 학교(사이트)를 운영하는 담당자 한 명이 맡습니다. |
| **교사** | 클래스·과제·문제은행을 운영하고, AI 채점을 검토·공개하며, 대시보드·분석·공지를 사용합니다. |
| **학생** | 클래스에 들어가 과제를 제출하고, 피드백을 확인하고, 적응형 문제를 풉니다. |

### 비밀번호 변경

모든 역할이 언제든 스스로 바꿀 수 있습니다.

1. 화면 **우측 상단의 이름**을 눌러 **계정 설정**으로 들어갑니다.
2. **비밀번호 변경**에서 새 비밀번호를 입력하고 저장합니다. (6자 이상, 이전과 다른 비밀번호)

## 관리자 가이드

### 교사 계정 발급

교사는 스스로 가입할 수 없습니다. 관리자가 계정을 만들어 임시 비밀번호를 전달합니다.

1. **관리자 페이지**(`/admin`)로 들어갑니다.
2. 교사로 쓸 **이메일과 이름**을 입력하고 계정을 발급합니다.
3. 화면에 **임시 비밀번호가 한 번만** 표시됩니다. 복사해서 해당 교사에게 전달하세요.
   (이 비밀번호는 다시 볼 수 없습니다. 그 자리에서 안전하게 전달하세요.)
4. 교사는 그 이메일·임시 비밀번호로 로그인한 뒤, 계정 설정에서 비밀번호를 바꿉니다.

> ⚠️ **주의** — 보안을 위해 자율 가입은 학생만 가능합니다. 교사·관리자 권한은 관리자만 부여할 수 있습니다.

## 교사 가이드

### 1. AI API 키 등록 (가장 먼저)

AI 채점·피드백·세특 초안·문항 추출·학습 분석은 **선생님 본인의 생성형 AI 키**로 실행됩니다.
키를 등록하지 않으면 AI 기능이 동작하지 않습니다.

1. 우측 상단 이름 → **계정 설정** → **생성형 AI API 키**로 들어갑니다.
2. 제공사를 고릅니다. **Google Gemini · OpenAI · Anthropic** 중 하나를 쓸 수 있습니다.
   (Gemini는 https://aistudio.google.com/apikey 에서 무료로 키를 만들 수 있습니다.)
3. 발급받은 **API 키**를 붙여넣고 저장합니다.
   저장할 때 실제로 한 번 호출해 키가 맞는지 자동 검증합니다. "설정됨"으로 바뀌면 완료입니다.

> 💡 **보관 방식** — 입력한 키는 암호화되어 저장되고 화면에 다시 표시되지 않습니다. 실제 여러 명이
> 쓴다면 각 제공사 콘솔에서 **사용량·예산 한도**를 걸어 두는 것을 권장합니다.

### 2. 클래스와 참여 코드

클래스는 과제·문제은행·공지가 묶이는 기본 단위입니다.

1. **새 클래스**를 만들고 이름을 정합니다.
2. 생성되면 **참여 코드**가 나옵니다. 이 코드를 학생들에게 알려 줍니다.
3. 학생이 코드를 입력해 들어오면 클래스 상세 화면 **참여 학생** 목록에 나타납니다.

### 3. 과제와 채점 기준

채점 기준은 AI가 채점할 때 그대로 근거로 삼습니다. 구체적일수록 채점이 정확합니다.

1. 클래스에서 **새 과제**를 만들고 제목·과목·마감일을 입력합니다.
2. 채점 방식을 고릅니다. **점수(숫자)** 또는 **등급(상·중·하 등)**.
3. **채점 기준**을 등록합니다. 영역·배점 단계별로 나눠 적으면 결과가 항목별로 정리되어 보기 좋습니다.

> 💡 **더 빠르게** — 학기 평가계획 PDF가 있다면, 하나하나 만들 필요 없이
> [평가계획 가져오기](#5-평가계획-가져오기)로 수행평가 항목을 한꺼번에 만들 수 있습니다.

### 4. AI 채점 · 검토 · 공개

학생이 제출한 파일을 AI가 채점 기준대로 채점합니다. 교사가 반드시 검토한 뒤 공개합니다.

1. 과제의 **제출물** 목록에서 학생 제출물을 엽니다.
2. **AI 채점**을 누릅니다. 잠시 후 결과가 생성됩니다.
   (PDF는 표·그림·사진까지 통째로 AI에 전달해 채점에 반영합니다.)
3. 결과를 확인합니다. **점수 · 학생용 피드백 · 세특 초안 · 채점 근거**가 만들어집니다.
   (세특 초안은 수식·영어 금지 등 학교생활기록부 규정을 반영합니다. 채점 근거는 교사만 봅니다.)
4. 필요하면 내용을 **수정**한 뒤 **학생에게 공개**합니다. 공개 전에는 학생에게 보이지 않습니다.

> ⚠️ **주의** — AI 채점 결과는 초안입니다. 점수와 피드백은 반드시 교사가 확인·수정한 뒤 공개하세요.
> **세부능력 및 특기사항 초안은 학생에게 공개되지 않습니다.**

### 5. 평가계획 가져오기

학기 평가계획 PDF를 올리면 AI가 수행평가 항목별로 분해해 과제 초안을 한 번에 만들어 줍니다.

1. **평가계획 가져오기**에서 평가계획 **PDF를 업로드**합니다.
2. AI가 항목별로 **성취기준 · 평가요소 · 배점 · 채점기준 · 평가방법 · 유의점**을 구조화해 추출합니다.
3. 위저드에서 항목을 **검토·수정**합니다. 전체 선택/해제, 병합도 됩니다.
4. 원하는 **클래스들을 골라** 과제를 일괄 생성합니다.

### 6. 문제은행 (적응형 문제풀이)

클래스별 문제은행을 만들면 학생이 스스로 문제를 풀 수 있습니다. 오답 시 같은 개념 → 난이도 순으로
다음 문항이 자동 선정됩니다.

**A. 문항 직접 입력** — 유형(객관식/서술형)·발문·보기·정답·난이도·개념 키워드·단원을 입력합니다.
수식은 `$...$` 안에 LaTeX로 쓰면 예쁘게 표시됩니다.

**B. 문제지 PDF 일괄 추출**

1. 문제지 **PDF를 업로드**하면 AI가 문항을 한꺼번에 추출합니다.
2. 그림이 필요한 문항은 **PDF에서 영역을 드래그**해 그림을 잘라 붙일 수 있습니다.
3. 위저드에서 정답·보기를 확인·수정한 뒤 **일괄 생성**합니다.

> 💡 **동작 방식** — 객관식은 정확 일치로, 서술형은 AI가 정오답을 판단합니다. 한 회차 동안 푼 문항은
> 다시 나오지 않고, 피드백은 정답을 직접 알려주지 않습니다.

### 7. 대시보드와 학습 분석

**대시보드 (첫 화면)**

- 요약 타일: 클래스·학생 수, 진행 중 과제, 검토 대기 건수
- 검토·채점 대기, 마감 임박 과제(제출 현황)
- 클래스별 정답률, 학습 지원이 필요한 학생

**클래스 학습 분석**

- 개념·유형·난이도별 통과율 표와 **AI 약점 분석**
- **학생 피드백 모아보기**에서 학생별 AI 피드백을 열람하고, 문항별·종합 **교사 피드백**을 남길 수 있습니다.

### 8. 공지

클래스 학생 전체에게 공지를 올릴 수 있습니다.

1. 클래스 상세 화면에서 **공지**를 작성해 게시합니다.
2. 게시한 공지는 해당 클래스 학생들의 대시보드에 표시됩니다.

## 학생 가이드

### 1. 가입과 클래스 입장

1. 로그인 화면의 **회원가입**에서 이메일·비밀번호로 가입합니다.
2. 선생님이 준 **참여 코드**를 입력해 클래스에 들어갑니다.

> ⚠️ **주의** — 같은 참여 코드를 두 번 눌러도 한 번만 등록됩니다. 클래스가 안 보이면 코드를 다시 확인하세요.

### 2. 과제 제출

1. 대시보드나 클래스에서 제출할 **과제**를 엽니다.
2. 과제 **파일을 업로드**합니다. (지원 형식은 [아래 표](#파일-형식-안내) 참고)

> 💡 **알아두기** — 다시 제출하면 이전 제출 파일과 채점 결과는 덮어써집니다. 한글 파일명도 그대로 쓸 수 있습니다.

### 3. 피드백 확인

선생님이 검토·공개한 뒤에 피드백이 보입니다.

- 대시보드에서 **점수**와 **선생님이 공개한 피드백**(종합·문항별)을 확인합니다.
- 문제풀이에서 틀린 개념은 **복습 필요 개념** 카드로 정리됩니다.

> 💡 **안심하세요** — 새로고침하거나 다른 탭에 다녀와도 이미 받은 AI 피드백은 바뀌지 않고 그대로 남습니다.

### 4. 문제 풀기

단원을 고르면 문제가 하나씩 나오고, 결과에 따라 다음 문항이 자동으로 정해집니다.

1. 클래스의 **문제 풀기**에서 단원을 선택합니다.
2. 문제를 풀고 제출하면 **정오답과 피드백**이 표시됩니다.
   (피드백은 정답을 직접 알려주지 않고, 스스로 다시 풀도록 힌트를 줍니다.)
3. 틀리면 **개념 설명**이 함께 나오고, 같은 개념의 다른 문항이 이어집니다.
4. 단원의 문항을 모두 통과하면 **단원 완료** 화면이 나옵니다.

## 파일 형식 안내

과제 제출과 자료 업로드에 쓰이는 형식입니다.

| 형식 | 용도 | 비고 |
|---|---|---|
| `.pdf` | 과제 제출 · 평가계획 · 문제지 | 표·그림·사진까지 AI가 인식 (원본을 통째로 전달) |
| `.docx` | 과제 제출 | 텍스트 추출로 채점 |
| `.hwpx` | 과제 제출 | 한글에서 "다른 이름으로 저장 → HWPX". 표 구조·이미지 내용은 반영 제한 |
| `.txt` | 과제 제출 | 텍스트 채점 |

> ⚠️ **주의** — 구버전 바이너리 `.hwp`는 지원하지 않습니다(`.hwpx`만). 아주 큰 PDF(대략 4.5MB 이상)는
> 업로드가 막힐 수 있으니, 스캔 이미지가 많은 파일은 용량을 줄여 올리세요.

## 자주 묻는 질문

**Q. AI 채점 버튼을 눌러도 결과가 안 나와요.**
대부분 **담당 교사의 AI API 키가 등록되지 않았거나 한도를 초과**한 경우입니다. 교사는
**계정 설정 → 생성형 AI API 키**에서 키가 "설정됨"인지 확인하고, 제공사 콘솔에서 사용량·결제 상태를 확인하세요.

**Q. 세부능력 및 특기사항 초안은 학생도 볼 수 있나요?**
아니요. 세특 초안과 채점 근거는 교사만 볼 수 있고, 학생에게는 공개되지 않습니다. 학생에게는 점수와
교사가 공개한 피드백만 보입니다.

**Q. 파일이 업로드되지 않아요.**
지원 형식(**pdf · docx · hwpx · txt**)인지, 용량이 너무 크지 않은지 확인하세요. `.hwp`(구버전)는
지원하지 않으니 한글에서 **HWPX**로 저장해 올리세요. 한글 파일명은 그대로 써도 됩니다.

**Q. 시간이 실제 한국 시간과 다르게 보여요.**
모든 날짜·시간은 **한국 표준시(KST, 서울 기준)**로 표시됩니다. 기기 시간대와 무관하게 동일하게 보입니다.

**Q. 같은 문제가 계속 나오거나, 반대로 너무 빨리 끝나요.**
문제풀이는 한 회차 동안 푼 문항을 제외하고, 오답이면 같은 개념을 먼저 다시 냅니다. 화면을
**새로고침하거나 "다시 도전"**하면 회차가 초기화됩니다. 단원의 모든 문항을 통과하면 "단원 완료"로 끝납니다.

**Q. 교사·관리자 계정으로 직접 가입할 수 있나요?**
아니요. 보안을 위해 자율 가입은 학생만 됩니다. 교사 계정은 관리자가 발급하고, 첫 관리자는 사이트
운영자가 별도로 지정합니다.
